Política de Privacidade e Termos de Serviço - Ofertas do Kaka
Este serviço opera exclusivamente como um publicador automatizado de conteúdo em redes sociais.
Coleta de Dados: O sistema não coleta, armazena, processa ou compartilha dados pessoais, informações de navegação ou credenciais de terceiros.
Uso da API: A integração com a API é utilizada estritamente para o upload automatizado de vídeos de ofertas na conta oficial do projeto.
Contato: Para dúvidas, entre em contato através do nosso canal oficial.
